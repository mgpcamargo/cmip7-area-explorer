1. How CMIP7 Data Access Works

          
    
            
  • Modern catalog search: CMIP7 replaces legacy portals with web catalogs (discovery.east.esgf.io, api.stac.esgf.ceda.ac.uk).
    • 
            
  • Simple sign-in (No OpenID): Sign in to MetaGrid (metagrid.esgf-west.org) using an institutional login or GitHub when needed.
    • 
            
  • Global files + local Python cropping: Official ESGF mirrors store full-globe .nc files. This site builds a Python script (intake-esgf + xarray) that, when you run it on your computer, crops the data to your box and saves a smaller .nc file.
    • 
          

        

        

          
2. How CMIP7 Names Variables (Plain Guide)

          
Instead of CMIP6 names like day.tasmax, CMIP7 keeps the short name first and appends details after an underscore:

          
tas_tmax-h2m-hxy-u

          
    
            
  • tas — base variable (air temperature; pr = precipitation, tos = sea surface temp)
    • 
            
  • tmax / tavg — daily maximum vs. time average
    • 
            
  • h2m — height/level (2m above ground; u = standard surface)
    • 
            
  • u / sea / lnd — coverage mask (everywhere, ocean-only, or land-only)
    • 
          

        

        

          
3. Grids & Available Experiments

          
    
            
  • Standardized grids (grid_label): Codes like g110 (atmosphere/land) or g126 (ocean) identify shared grids. Leave set to Any unless you need a specific grid.
    • 
            
  • Active experiments: Includes historical, esm-hist (emissions-driven), piControl, amip, and future scenarios (scen7-vl very low, scen7-m medium, scen7-h high emissions).
    • 
          

        

        

          
4. Which Download Option Should I Pick?

          
    
            
  • I only want my selected box: Download Python Subset (.py) · Area Only ★ (or copy Step 3's script) and run it in Python on your machine — running the script fetches the data and saves a cropped .nc file for your box.
    • 
            
  • I want raw .nc files directly: Use Download Global .nc ↗ or wget (.sh) · Full Global Files, then crop locally afterward with cdo sellonlatbox,....
    • 
            
  • Large multi-model downloads: Use Globus via metagrid.esgf-west.org or the ESGpull CLI (v0.10.0+).
