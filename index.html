1. ESGF-NG Architecture & Authentication

          
    
            
  • STAC APIs replace Solr: Discovery runs via SpatioTemporal Asset Catalogs (discovery.east.esgf.io/search, discovery.west.esgf.io/search, api.stac.esgf.ceda.ac.uk/search).
    • 
            
  • No OpenID: Authentication on MetaGrid (metagrid.esgf-west.org) uses institutional SSO or GitHub.
    • 
            
  • Streaming & Virtual Zarr: intake-esgf + xarray allow lazy subsetting before writing local NetCDF4 files.
    • 
          

        

        

          
2. CMIP7 Branded Variables & MIP-DRS7

          
Static CMIP6 table prefixes (e.g. Amon.tas, day.tasmax) are replaced by branded variables encoding temporal, vertical, horizontal, and area sampling:

          
tas_tmax-h2m-hxy-u · pr_tavg-u-hxy-u · tos_tavg-u-hxy-sea

          
    
            
  • tavg / tmax / tmin: Temporal reduction
    • 
            
  • h2m / h10m / u: Vertical sampling level
    • 
            
  • u / sea / lnd: Area mask (cmip7:area_label)
    • 
          

        

        

          
3. Strict Grid Labels & Active Experiments

          
    
            
  • Registered grid_labels: CMIP7 uses explicit standardized grid IDs (such as g110, g126, g108, g124).
    • 
            
  • Assessment Fast Track (AFT): Active experiments include historical, esm-hist, piControl, 1pctCO2, abrupt-4xCO2, amip, and ScenarioMIP pathways (scen7-vl, scen7-m, scen7-h).
    • 
          

        

        

          
4. Choosing the Right Download Path

          
    
            
  • Regional Subsets (<20% globe): Use intake-esgf + xarray.sel() to pull only your lat/lon/time slice.
    • 
            
  • CLI / Browser Cart: Use the Download Cart above (.sh / .py) or scripts/cmip7_check_area.py / ESGpull (v0.10.0+).
    • 
            
  • Bulk Multi-Model Transfers: Use Globus via MetaGrid / ESGF Tier-1 nodes.
