            01
            
How CMIP7 Data Access Works

          

          
    
            
  • Modern STAC catalog search: CMIP7 replaces legacy ESGF nodes with cloud-friendly STAC APIs (discovery.east.esgf.io, api.stac.esgf.ceda.ac.uk).
    • 
            
  • Institutional / GitHub sign-in (No OpenID): Authenticate on MetaGrid (metagrid.esgf-west.org) using Institutional SSO or GitHub when required.
    • 
            
  • Global files + local Python cropping: Official ESGF mirrors host full-globe .nc files under CC-BY-4.0. This tool builds an intake-esgf + xarray script that subsets your exact bounding box and saves a regional NetCDF4 file.
    • 
          

        

        

          

            02
            
CMIP7 Branded Variable Syntax

          

          
Instead of CMIP6 table prefixes like day.tasmax, CMIP7 places the root physical variable first followed by structured branding suffixes:

          
tas_tmax-h2m-hxy-u

          
    
            
  • tas: root variable (air temperature; pr = precipitation, tos = sea surface temp)
    • 
            
  • tmax / tavg: temporal statistic (daily maximum vs. time mean)
    • 
            
  • h2m: vertical coordinate (2m height; u = unlevelled/surface)
    • 
            
  • u / sea / lnd: horizontal area mask (unmasked everywhere, ocean-only, or land-only)
    • 
          

        

        

          

            03
            
Standardized Grids & Experiments

          

          
    
            
  • Grid labels (grid_label): Codes such as g110 (atmosphere/land) or g126 (ocean) identify MIP-DRS7 grid definitions. Leave set to Any unless comparing a single target grid.
    • 
            
  • Core & ScenarioMIP experiments: Includes historical, esm-hist (emissions-driven), piControl, amip, idealized CO₂ runs, and scen7-vl / scen7-m / scen7-h projections.
    • 
          

        

        

          

            04
            
Choosing a Download Workflow

          

          
    
            
  • Regional subset only: Click Download .py (or Copy) under Python Area Crop ★ in Step 03 and run it locally in Python to fetch and save a cropped .nc file.
    • 
            
  • Direct full-globe NetCDF files: Use Download Global .nc ↗ or wget (.sh), then crop locally with cdo sellonlatbox,....
    • 
            
  • Advanced / HPC workflows: Open Other methods ▾ in Step 03 for raw STAC API (cURL) queries, ESGpull CLI (v0.10.0+), or Globus via ESGF MetaGrid.

Glossary

        


        

          

            
              

                Acronym
                Meaning
                Explanation
              

            
            
              

                AMIP
                Atmospheric Model Intercomparison Project
                A standardized climate experiment running atmosphere-only models forced by observed sea surface temperatures and sea ice.
              

              

                API
                Application Programming Interface
                A structured software interface allowing scripts and web applications to query live ESGF-NG catalogs programmatically.
              

              

                CC-BY-4.0
                Creative Commons Attribution 4.0 International
                The open data license under which CMIP7 model outputs are published, requiring attribution to the modeling groups.
              

              

                CDO
                Climate Data Operators
                A command-line toolkit for manipulating gridded climate files, used via sellonlatbox to crop global NetCDF files locally.
              

              

                CLI
                Command-Line Interface
                A text-based terminal interface used to execute tools such as esgpull, cdo, and standalone Python scripts.
              

              

                CMIP7
                Coupled Model Intercomparison Project Phase 7
                The seventh phase of the global WCRP framework coordinating standardized climate model experiments and data releases.
              

              

                CMIP7-AFT
                CMIP7 Assessment Fast Track
                Priority CMIP7 model simulations released ahead of the full archive to support upcoming international climate assessments.
              

              

                CMIP-IPO
                CMIP International Project Office
                The international coordination office supporting CMIP governance, technical standards, and modeling community outreach.
              

              

                CMOR
                Climate Model Output Rewriter
                The standard software library and formatting convention traditionally used to structure climate model variables and metadata.
              

              

                CORS
                Cross-Origin Resource Sharing
                A browser security mechanism enabled by ESGF-NG STAC endpoints so this client-side page can query live datasets directly.
              

              

                cURL
                Client URL
                A command-line utility for transferring data over HTTP/HTTPS, used in Step 03 to send STAC catalog search requests.
              

              

                ENSO
                El Niño–Southern Oscillation
                A major coupled ocean–atmosphere climate oscillation in the tropical Pacific, monitored via regions such as the Niño 3.4 box.
              

              

                EOX
                EOX IT Services
                The geospatial service provider hosting the open Copernicus Sentinel-2 Cloudless satellite tile mosaic used in the map viewer.
              

              

                ESA
                European Space Agency
                The European space organization operating the Copernicus Sentinel-2 satellites that capture the Satellite layer imagery.
              

              

                ESGF
                Earth System Grid Federation
                The global federated data infrastructure that stores and distributes CMIP climate simulation outputs worldwide.
              

              

                ESGF-NG
                Earth System Grid Federation Next Generation
                The modernized ESGF architecture built around cloud-friendly STAC search APIs and federated single sign-on.
              

              

                ESM
                Earth System Model
                A comprehensive climate model used in runs like esm-hist that interactively couples physics with the carbon cycle.
              

              

                HPC
                High-Performance Computing
                Supercomputing clusters and institutional workstations commonly used to download and process multi-model NetCDF ensembles.
              

              

                IAG/USP
                Institute of Astronomy, Geophysics and Atmospheric Sciences / University of São Paulo
                The academic institute and university in Brazil where CMIP7 Area Explorer was created.
              

              

                JSON
                JavaScript Object Notation
                A lightweight text data format used by STAC APIs to return dataset metadata, footprints, and file asset URLs.
              

              

                MIP-DRS7
                Model Intercomparison Project Data Reference Syntax for CMIP7
                The official CMIP7 metadata and naming standard defining branded variables, grid labels, realms, and directory layouts.
              

              

                MIT
                Massachusetts Institute of Technology (License)
                The permissive open-source software license governing the CMIP7 Area Explorer web application and companion script.
              

              

                NetCDF4
                Network Common Data Form (Version 4)
                An HDF5-backed binary scientific file format used across CMIP to store multidimensional gridded climate variables.
              

              

                OpenID
                Open Identity (Legacy ESGF Authentication)
                The retired federated login system from legacy ESGF portals, replaced by Institutional SSO and GitHub in ESGF-NG.
              

              

                ScenarioMIP
                Scenario Model Intercomparison Project
                The CMIP activity defining future emissions and socioeconomic projection experiments such as scen7-vl, scen7-m, and scen7-h.
              

              

                SSO
                Single Sign-On
                Modern institutional or GitHub authentication used on ESGF MetaGrid when transferring large ensembles via Globus.
              

              

                STAC
                SpatioTemporal Asset Catalog
                An open geospatial catalog specification enabling fast filtering of climate datasets by bounding box, time, and model properties.
              

              

                WCRP
                World Climate Research Programme
                The international scientific body coordinating CMIP and global climate variability and projection research.
              

              

                WGS84
                World Geodetic System 1984
                The standard geographic latitude/longitude reference system used for bounding boxes and satellite tile layers.
              

              

                Zarr
                Zarr Chunked Array Format
                A cloud-optimized chunked array format supported alongside NetCDF by xarray and intake-esgf.
              

            
          

        

      


      

        

          

            
              
            
            
Frequently Asked Questions

          

          

            
            
          

        


        

          

            01 Does this website crop and download NetCDF files directly inside my browser?
            

              Official ESGF-NG mirrors distribute full-globe (_glb_) NetCDF4 files that often span hundreds of megabytes to several gigabytes per simulation. Rather than pulling multi-gigabyte arrays into browser memory, CMIP7 Area Explorer queries live ESGF-NG STAC catalogs in real time and generates a reproducible intake-esgf + xarray Python script (or wget + cdo sellonlatbox workflow) that subsets and saves your exact bounding box on your workstation or HPC environment.
            

          


          

            02 Why do CMIP7 variable names look like tas_tavg-h2m-hxy-u instead of CMIP6's Amon.tas?
            

              Under the MIP-DRS7 standard, CMIP7 replaces opaque CMOR table names with self-describing branded variable names formatted as <root>_<temporal>-<vertical>-<horizontal>-<area_mask>. For example, daily maximum and minimum 2m air temperature share the physical root tas and are distinguished explicitly as tas_tmax-h2m-hxy-u and tas_tmin-h2m-hxy-u. Step 02 displays both the new CMIP7 branded syntax and legacy CMIP6 equivalents side by side.
            

          


          

            03 How are 0°–360° longitudes and Prime Meridian (0°) crossings handled?
            

              Climate models store native longitudes on either 0°..360°E or -180°..180°. To prevent empty slices or coordinate mismatches, the Step 03 Python script automatically checks ds.lon.max() > 180 at runtime and normalizes longitudes to -180..180 before calling ds.sel(...), so regions crossing 0°E (such as Europe, Mediterranean, or West Africa) work seamlessly.
            

          


          

            04 What do the ⚠ No ocean in box or ⚠ Low/no sea ice status warnings mean?
            

              When you draw or move a box on the 1:50m map, the portal tests spatial intersection against land polygons, ocean waters, and high-latitude polar zones (|lat| ≥ 58°). If you select an inland continental box (e.g., central Amazonia), ocean-masked variables (-sea, such as tos or fgco2) will contain only missing/masked grid cells (NaN). These flags are advisory diagnostics—you can still click any variable and query the catalog.
            

          


          

            05 Why did a live ESGF-NG scan return 0 live datasets found for a specific combination?
            

              CMIP7 and Assessment Fast Track (CMIP7-AFT) simulations are progressively published across federated STAC endpoints (discovery.east.esgf.io and api.stac.esgf.ceda.ac.uk). If a specific scenario or grid label currently returns zero matches, try leaving grid_label set to Any, testing core experiments such as historical, esm-hist, piControl, scen7-vl, or scen7-h, or running the standalone CLI script scripts/cmip7_check_area.py.
            

          


          

            06 Do I need an ESGF OpenID account or API key to use this portal or download files?
            

              No API key or login is required to use CMIP7 Area Explorer or download public HTTPS NetCDF assets. Legacy ESGF OpenID has been retired in ESGF-NG; if you later use bulk transfer services such as Globus on ESGF MetaGrid, sign-in uses modern Institutional SSO or GitHub authentication.
            

          


          

            07 How do the Atlas and Satellite map views and overlays help area selection?
            

              Click the stacked Layers icon beneath the zoom buttons (+ / − / ⟲) to switch between the fast offline 1:50m Vector Atlas and Satellite (ESA Copernicus Sentinel-2 Cloudless), and toggle Borders & Labels or the Lat/Lon Grid.
            

          


          

            08 What licenses govern CMIP7 datasets and this web application, and how do I cite it?
            

              All CMIP7 model outputs are released under Creative Commons Attribution 4.0 (CC-BY-4.0)—please cite the participating modeling groups and WCRP CMIP7 in publications. CMIP7 Area Explorer is an independent, community-contributed open-source utility (MIT License) developed at IAG/USP; formal software citation metadata is available via CITATION.cff on GitHub.
